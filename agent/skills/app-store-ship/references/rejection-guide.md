# Common Rejections

The guidelines apps break most often, what each means, and how to fix it.

Also called: rejected, rejection, app store rejection, why was my app rejected, app review guidelines, guideline numbers, metadata rejected, Guideline 2.1, Guideline 2.3, Guideline 2.3.3.

## Pitfalls

- **The rejection message names the guideline.** Start with that number, fix everything it lists, and reply in App Store Connect if anything is unclear.
- **The guidelines change.** Apple calls them a living document. As of October 2026, the latest update is dated June 8, 2026.

## Guide

Every rejection message cites one or more numbered App Review Guidelines. A few numbers come up again and again. Find yours below, then fix the cause, not just the symptom.
