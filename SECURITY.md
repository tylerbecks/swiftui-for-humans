# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue or pull request.

1. Go to the repository's [Security tab](https://github.com/tylerbecks/swiftui-for-humans/security).
2. Choose **Report a vulnerability**.
3. Describe what you found, how to reproduce it, and what someone could do with it.

Only the maintainer sees the report. You'll get a reply within a week, and once a fix ships you'll be credited in the advisory unless you'd rather not be.

## What's in scope

- The iOS and Mac apps in this repository
- The website in `website/` (swiftuiforhumans.com)
- Anything people install from this repository into their own tools, such as agent skills, scripts, and hooks
- The GitHub Actions workflows in `.github/`

## Supported versions

Only the latest release of the apps and the current `main` branch get fixes.
